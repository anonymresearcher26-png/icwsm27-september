# Welcome to the analysis code of the paper "_Changes in Private Messaging Among Ukrainian Instagram Users Following Russia's Full-Scale Invasion of Ukraine_" submitted to ICWSM on 15th of September, 2026! 

This is an anonymous repository. Upon acceptance, the code will be transferred to the official repository of the research lab. 
The goal of this analysis code is to illustrate the analytical procedures underlying the results of the paper. The research data is not included in the current repository. It will be published upon acceptance and made available to qualifying researchers under an end-user license agreement. Hence, treat the code as a replication rather than reproducilibity material at the current stage. 

The structure of the repository: 
- The requirement file includes all the packages needed to run the code.
- All analyses are available under code/scripts. Heleper functions are available under code/modules.
- The scripts are organized based on the order in which the results appear in the paper. They are also numbered to help you follow the order of analysis.
